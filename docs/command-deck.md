# The Command Deck

**Deck** on the top bar (or `/deck`) shows Jarvis's crews as a live map. Each business is a wing around the core,
each agent is a station, and everything on it comes from what's really happening.

## Reading the map

| You see | It means |
|---|---|
| Blue, pulsing | The agent is working on a task right now |
| Dark blue | It has work queued up next |
| Amber, pulsing | It's waiting on you: a quick question or an approval |
| Dim | Standing by |
| Dashed outline | The crew is paused or not approved yet |
| Dashed line with an arrow | This agent may hand work to that one |
| A light moving along a line | A handoff is happening (in the last 30 minutes) |
| Small amber number | How many things are queued or waiting for that agent |

Tap an agent (or pick it from the list on a phone) to see what it's doing, its last result, what it cost this week,
its job, who it can hand work to, and a box to give it a task directly.

## Handoffs

Agents can pass finished work to a teammate in the same crew, along the routes you allow. Toggle them on an agent's
panel under **Can hand work to**. The starter routes:

- LaunchPad Local: Prospector → Outreach Writer → Audit Desk → Client Success
- Custom Photo Gifts: Shop Marketer → Customer Care, Order Desk → Customer Care
- Nina: Growth Analyst → Content Planner and UGC Ad Maker; Content Planner and UGC Ad Maker → Community Manager

Limits: a piece of work can be handed on at most 3 times, one task can hand off to at most 2 teammates, and the same
handoff is never made twice. Anything that sends, spends or posts still comes to you for approval.

## Quick questions

When a task is unclear and guessing would waste the work, an agent asks you one question with 2–4 answer buttons. Its
task waits. Answer with one tap on the deck, in **Waiting on you** on the Command Center, from the phone alert, or by
voice ("Jarvis, any questions from the crew?"). The agent picks the task back up with your answer.

## Where it runs

Same as the rest of Jarvis: on Render (nothing to install, works from any phone or browser) or on your own computer
(see [moving-off-render.md](moving-off-render.md)). The deck works the same either way.
